# 中国法律技能调研

## 1. 技能和数据库各管一层

法律技能若只靠模型记忆写「《某某法》第某条」，条号、效力和版本都可能是编的。公开仓库把流程拆成两层：

| 层 | 做什么 | 不做什么 |
|----|--------|----------|
| Skill | 规定先检索、再推理、再出草稿；没查到就标「待检索」 | 不自带法规全文库 |
| MCP | 用账号令牌调厂商的法规、案例、企业数据 | 不替技能决定论证结构 |

未配置任何数据库时，技能仍可按清单跑，但引用必须标成待核查。接上 MCP 之后，同一套步骤改为调工具，并在文中注明来源。

## 2. GitHub 上的技能仓库

检索时星数最高、且明确面向中国大陆成文法的是 [THUYRan/Legal-Skills-Chinese](https://github.com/THUYRan/Legal-Skills-Chinese)（页面约 **565** 星）。README 写明 **38** 个由法律专业人员编写的技能，默认法域是中国大陆成文法：除最高人民法院指导性案例外，案例没有普遍约束力。技能分成可单用的原子步骤（检索一条、抽一组要件、做一次演绎）和少量复合流程。检索类不绑死某一家库，已验证的接入是北大法宝 MCP。三个和数据库直接相关的技能是：

| 技能目录 | 用途 |
|----------|------|
| `case-retrieval` | 类案、判决检索 |
| `legal-article-retrieval` | 法规、法条检索 |
| `legal-norm-validity-check` | 法条是否仍有效、条号是否幻觉 |

令牌只放在本机 MCP 配置里，不要写进 `SKILL.md` 再提交。

[pa1nrui1/legal-skills](https://github.com/pa1nrui1/legal-skills) 把咨询、诉讼、刑辩、劳动、破产、合同、合规、检索和文书收成可路由的工作流，入口技能要求先读总控再进子技能。作者在 README 中署名为执业律师。它强调来源边界和出稿前人工复核，而不是单点提示词。

[NEU-ZHA/legal-ai-skills](https://github.com/NEU-ZHA/legal-ai-skills) 面向北大法宝：安装 MCP、按积分选择关键词或语义检索、引注核验、DOCX。README 写明关键词类调用更省积分，语义检索、溯源只在必要时升级。没有令牌时仍可用写作和 Word 技能，检索改为网页兜底并标明未核验。

厂商自己的技能合集在 Gitee，不在 GitHub：[pkulaw/pkulaw-skills](https://gitee.com/pkulaw/pkulaw-skills)（MIT）。它与 `@pkulaw/mcp-cli` 和法宝网关对齐，包含检索底稿（法规关键词、语义、精准法条、案例、引用加链接）以及庭前研判、执行、仲裁、公司法体检、处罚应对、签发前核验、法条时效等流程。官方要求先检索、引用可追溯。

其余仓库星数以各自页面为准，本文不把未核对的数字写成排名。

## 3. 华宇元典 MCP

华宇元典的接入仓库是 [yuandian-ailaw/yuandian-mcp-server](https://github.com/yuandian-ailaw/yuandian-mcp-server)，npm 包名 `yuandian-mcp-server`。进程启动时读取[元典开放平台](https://open.chineselaw.com/)的接口目录，把每个开放接口注册成一个 MCP 工具。业务请求转发到 `https://open.chineselaw.com/open/{routeKey}`，请求头用 `X-API-Key`。Node.js 需 20 及以上。

```json
{
  "mcpServers": {
    "yuandian-mcp-server": {
      "command": "npx",
      "args": ["-y", "yuandian-mcp-server"],
      "env": {
        "YUANDIAN_API_KEY": "你的_api_key"
      }
    }
  }
}
```

固定工具有两个：`yuandian_list_apis` 列出本次启动看到的接口，`yuandian_get_api_document` 读取某个接口的 Markdown 说明。其余工具名是 `yuandian_{routeKey}`，例如法规向量检索 `yuandian_law_vector_search`、企业检索 `yuandian_rh_enterpriseSearch`。因此工具清单会随开放平台目录变化，不以某一篇旧文档里的全表为准。

平台覆盖法律法规、裁判文书和企业信息（工商、涉诉等，以接口广场当时上架的为准）。密钥在开放平台申请。README 里写过一段按月赠送积分的活动，截止日期已过，是否延续以平台页面为准。

## 4. 北大法宝 MCP

公开产品名是 **北大法宝 MCP**（[mcp.pkulaw.com](https://mcp.pkulaw.com/)），数据侧对应北大法宝法规与案例库。官网同时提供对话用的 MCP 和命令行 `@pkulaw/mcp-cli`：对话由模型调工具，命令行不经过模型，适合批量查询。两套共用一个 Access Token。

与元典「一个进程、启动时动态注册」不同，法宝按**已开通的服务**发地址。第三方技能文档里的常见写法是：

```json
{
  "mcpServers": {
    "pkulaw": {
      "type": "http",
      "url": "https://apim-gw.pkulaw.com/{SERVICE_ID}/mcp",
      "headers": {
        "Authorization": "Bearer 你的_Token"
      }
    }
  }
}
```

`SERVICE_ID` 和 Token 在控制台领取，没有一个对所有人相同的公开 URL，所以技能仓库不应把占位地址提交进去。官网定价页还出现过按服务拆开的网关路径，以控制台当前下发的地址为准。

Legal-Skills-Chinese 的 `MCP-PKULAW.md` 把公开宣传的能力归成几类，并对应到自己的技能：

| 服务 | 作用 | 该仓库建议接到 |
|------|------|----------------|
| 法规语义检索、法规/法条关键词检索 | 用自然语言或关键词找法规、条文 | `legal-article-retrieval` |
| 案例语义检索、案例关键词检索 | 找类案、判决 | `case-retrieval` |
| 法条、案号识别与溯源 | 从正文认出引用并回到出处 | 检索与效力核验 |
| 修正生成中的法条 | 查条号错位、版本过期、虚构条文 | `legal-norm-validity-check` |

官网称服务在十项以上，其余以应用中心为准。定价页写明试用覆盖若干服务、按次计费；关键词检索与语义检索、识别溯源的扣次不同。NEU-ZHA 的技能把「先关键词、必要时再语义」写成默认路由，避免每问都走贵的语义接口。CLI 示例是全局安装后 `pkulaw-mcp init`，再执行如 `law-semantic` 这类子命令。具体子命令以 npm 包说明为准。

官方技能集 `pkulaw-skills` 与上述网关对齐，MIT。它把庭审、执行、仲裁路径写成步骤，并写明若干时间点（例如仲裁法修订本、公司法出资期限过渡），这些时点会过期，用之前要再核一次现行文本。

## 5. 怎么接到技能上

两家可以同时配。技能文档里的做法是逐个探测谁真正返回了结果，并在引用上分别标注来源，而不是把两家结果默默合成一条。元典用本地 `npx` 进程加 API Key；法宝用 HTTP 和 Bearer Token。密钥放环境变量或本机 MCP 配置，不进 Git。

推荐顺序：

1. 选定技能仓库（推理流程用 Legal-Skills-Chinese 或 legal-skills，法宝工作流用 pkulaw-skills）。
2. 只给需要检索的技能配置对应 MCP；写作、DOCX 不必先有令牌。
3. 用一条已知法规做冒烟，例如检索竞业限制经济补偿的现行规定，看返回是否带数据库出处。
4. 无结果或未配置时，输出保持「待检索」，不要改用模型记忆填条号。

## 6. 使用边界

这些仓库的免责声明一致：辅助阅卷和起草，不构成法律意见，不能直接对外发出。中国大陆成文法下，不能把普通判决写成普遍规则。法宝和元典都是账号制数据服务，额度、字段和是否含全文以合同与控制台为准。动态注册的元典工具名、法宝的 `SERVICE_ID` 都会变，技能里应写「调用检索工具」，不要把某天的工具全表抄死。

## 7. 小结

| 要点 | 结论 |
|------|------|
| 高星技能库 | Legal-Skills-Chinese，约 565 星、38 个中国法技能；检索以 MCP 为准，未接则标待查 |
| 其他技能 | pa1nrui1/legal-skills 偏全流程；NEU-ZHA/legal-ai-skills 与 pkulaw-skills 偏法宝检索和核验 |
| 华宇元典 | `yuandian-mcp-server`，启动时按开放平台目录注册工具，`X-API-Key` |
| 北大法宝 | `mcp.pkulaw.com`，按服务发 HTTP 地址，Bearer Token；另有 `@pkulaw/mcp-cli` |
| 接入 | 密钥只留本机；两家可并存，引用要写明来源 |

先接一家检索 MCP，用一条现行法条对一下原文，再把技能流程接到那一次真实返回上。
