# 大疆司空平台与智图客户端简介

> **大疆司空 2**（FlightHub 2）是行业机场和飞行器的云端作业平台：项目、设备、航线、直播、任务和媒体都在这里。第三方系统用 **OpenAPI** 按组织密钥调用这些能力，而不是重做一套飞控。航测成果若要在本机做成正射、三维或激光点云，用桌面软件 **大疆智图（DJI Terra）**。云端那套智图 API 的开发者页已写明于 2026 年 6 月停止维护，新接入应改走司空建模 API。接口路径以所部署版本的说明书为准，公有云和私有云文档是分开的。

## 1. 司空 2 管什么

司空 2 面向已接入云平台的机场（Dock）和行业飞行器。组织下面是项目，项目里绑定设备、航线库、地图标注和媒体文件夹。飞手或调度在网页上可以看直播、下发航线、回看轨迹。

公有版是大疆托管的云。私有版把同一套能力装到物理机、私有云或客户自己的公有云账号里，发布说明写核心功能与同期公有云对齐。另有预装私有版、云端建模和 4G 增强图传的一体机，可直连机场或经遥控器连飞机。

二次开发在私有版落地页上分成三块：OpenAPI、前端组件、司空 Sync。OpenAPI 是 RESTful 接口，用来让业务系统查询设备、下发任务、取媒体和模型。私有版 OpenAPI 从 V1.0 的约 67 个接口补到 V2.0 的 300 个以上，模块包括认证、组织项目、设备、直播、航线、任务、模型、标注。V2 把公有云和私有云文档拆开，示例工程在 [FlightHub-2-OpenAPI-V2-Demo](https://github.com/dji-sdk/FlightHub-2-OpenAPI-V2-Demo)。

## 2. OpenAPI 怎么串业务流程

调用前先在控制台建好组织和项目，并把机场、飞行器绑进项目。较新的鉴权说明写明：OpenAPI 做查询和调用，**不负责创建组织**。组织密钥是一张 JWT，放在每次请求的 Header 里，字段名是 `X-User-Token`（文档里也写作 `x-user-token`）。

密钥在「我的组织 → 组织设置」里复制。有的版面叫 OpenAPI，有的仍写在云端互联。刷新密钥后旧值立即失效。令牌对应的用户必须已经加入目标项目，并且角色允许该操作，否则鉴权失败。`org_uuid` 可从 JWT 载荷读出；项目 UUID 再调组织下的项目列表接口，取 `data.list` 里的 `uuid`。部分接口还要带 `X-Project-Uuid`。

业务系统通常按这个顺序串，而不是每个按钮各写一套协议：

```text
控制台：组织、项目、绑定机场与飞行器
  → 复制组织密钥，请求头带 X-User-Token
  → 列出项目，得到 proj_uuid
  → 列出项目设备与航线库
  → 创建航线任务（立即 / 定时 / 重复 / 连续）
  → 可选：申请飞行控制权并下发指令
  → 任务结束后取轨迹、飞行记录、媒体文件夹
  → 需要出图时，把媒体交给智图客户端或司空建模 API
```

航线任务创建在公开的调用指南里是 `POST /openapi/v0.9/task/api/v1/workspaces/{proj_uuid}/flight-tasks`。V2 私有云的路径前缀可能不同。对接时只使用与当前司空版本一致的那份文档，不要把 v0.9 示例和 v2.0 路径混在同一次发布里。

## 3. 一条航线任务的调用顺序

官方「执行航线任务」指南把一次飞行拆成这些调用。设备须已在对应项目中上线。

| 步骤 | 作用 |
|------|------|
| 获取项目列表 | 在组织下找到要作业的项目 |
| 获取项目设备 | 看机场、飞行器是否在线，以及拓扑关系 |
| 获取航线列表与详情 | 选定已经上传到项目航线库的航线 |
| 创建航线任务 | 立即执行，或设成定时、重复、连续任务 |
| 飞行控制（可选） | 任务中途接管并下发指令 |
| 任务详情与轨迹 | 状态、飞行记录、媒体文件夹 ID、轨迹 |

媒体文件夹 ID 是后续下载照片、录像的入口。业务系统若要在工单里展示「飞完了、片子在哪」，应等任务详情返回该 ID，再去媒体接口取文件，而不是凭任务创建成功就认为成果已落地。

直播、地图标注、模型列表属于同一套 OpenAPI 的其它模块，按项目 UUID 取。它们可以和任务并行接，但不是航线闭环的必经步骤。

## 4. 司空 Sync

私有版把早期的「云端互联」升级为 **司空 Sync**。它不替代 OpenAPI 的查询和下发，而是把司空里已经产生的数据推到外部系统：

| 能力 | 说明 |
|------|------|
| 文件同步 | 按文件类型、项目、存储桶交叉配置，可同时指向多个桶；同步完成后可选删除司空内源文件 |
| 遥测 | 把飞机姿态等数据实时推到第三方 |
| 直播转发 | 支持 RTSP |
| Event API | 按规则把司空内事件推到外部 |
| 空域 | 可接入第三方空域数据，在司空地图里一起显示 |

文件和事件走 Sync，任务编排走 OpenAPI。两边的密钥和项目范围要分开核对。

## 5. 大疆智图客户端

大疆智图是 Windows 上的重建软件，手册写明覆盖可见光二三维、激光雷达，以及 3D 高斯泼溅。和司空的分工是：司空负责飞和收素材，智图负责在本机把素材算成测绘成果。

按许可证分成三档（以手册「软件版本与功能比对」为准，机型列表会更新）：

| 版本 | 手册中的能力 |
|------|----------------|
| 农业版 | 农田与果树二维重建、多光谱二维、农业应用 |
| 标准版 | 在农业版上增加城市场景二维、三维、兴趣区域、输出坐标系、像控与缩放约束、热红外、激光点云精度优化、多显卡等 |
| 旗舰版 | 在标准版上增加电力线场景三维、精细化巡检、高斯泼溅 |

可见光二维常见产出是正射和数字表面模型（GeoTIFF，默认 UTM）。三维常见产出是 OSGB、B3DM、S3MB、OBJ 等网格，以及 LAS / LAZ / PNTS 点云，并带 `metadata.xml` 说明坐标系。空三报告和地图、模型质量报告在成果目录的 `report` 下。

像控点分两类：控制点参加平差，检查点只用来验收、不参与解算。刺点可以自动识别黑白靶标、手工点选，或由软件预测。已有 RTK 照片 POS 时，可以打开 POS 约束；手册给出的初始平面精度约 0.03 m、高程约 0.06 m，这是约束用的先验，不是对本测区成果的承诺。

激光雷达任务针对禅思 L 系列。手册写 L2、L3 的点云重建在相应版本可不另购智图授权即可出基础点云；精度优化和 DEM、等高线、TIN 等是否收费，以该版本发布说明为准。激光控制点按平面位置做局部高程改正，检查点在该点附近一定半径和高差内检查高程。计算可以单机，也可以在局域网里集群。点云异常时可用自标定导出标定文件，写回雷达存储卡。

可见光任务类型在云端 API 文档里曾对应 type 14（二维）、15（三维）、13（激光）。那套 `POST /v2/jobs/start` 与桌面端算法版本对齐（文档记到 Terra 4.5.0），并可用 `export_parameter` 让云端目录和本机智图目录一致，便于再导回桌面端。开发者站点已公告：**大疆智图 API 于 2026 年 6 月停止维护，请改到司空建模 API。** 桌面客户端本身仍按智图手册安装和激活，不要把停维理解成桌面软件下线。

## 6. 和司空怎么接

私有化部署手册支持用可视化方式同时装司空、Terra 和 4G 服务。一体机则预装私有版和云端建模模块。业务上可以收成一条链：

```text
司空项目绑定机场
  → OpenAPI 下发航线任务
  → 媒体回到项目文件夹
  → 司空 Sync 同步到对象存储（可选）
  → 司空建模 API 或本机大疆智图重建
  → 正射 / 三维 / 点云再交回业务 GIS
```

像控、坐标系和 RTK 状态要在起飞前定好。智图只能优化已有 POS 和控制点，不能补上没测的像控。

## 7. 适用边界

**适合。** 已有大疆机场或行业飞机，要在自有工单、巡检或测绘系统里查设备、下任务、取媒体，并在飞完后出正射或点云。

**不适合。** 用 OpenAPI 从零创建组织（按较新说明应在控制台完成）。把 v0.9 示例路径直接打到 V2 私有云。在智图 API 停维之后仍新写 `/v2/jobs/start`。没有控制点又要求绝对精度时，只靠软件开关不够。

## 8. 小结

| 要点 | 结论 |
|------|------|
| 司空 2 | 组织、项目、机场、航线、直播、任务、媒体的云平台；有公有版和私有版 |
| OpenAPI | Header 带组织密钥；先拿项目 UUID，再下发航线并取轨迹与媒体 |
| Sync | 把媒体、航线、飞行记录、遥测和事件推到外部存储或系统 |
| 智图客户端 | 本机二三维、多光谱、激光雷达重建；农业 / 标准 / 旗舰分档 |
| 云端重建 | 智图 API 已公告 2026 年 6 月停维，新流程走司空建模 API |
| 注意 | 公有云与私有云文档分开；密钥对应用户必须在目标项目里有权限 |

先在控制台完成绑定并复制组织密钥，用项目列表和一条立即航线把媒体文件夹跑通，再决定成果是进本机智图还是司空建模 API。
