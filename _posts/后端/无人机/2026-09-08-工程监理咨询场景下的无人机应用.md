# 工程监理咨询场景下的无人机应用

> 电力、光伏运维中的无人机分析多服务于设备缺陷库。工程监理与造价咨询需要对齐质量、进度、安全、投资的留证、预警与闭环。本文按监理业务划分场景，整理国内公开案例，并说明与运维巡检的差异。报道中的准确率与效率提升均为项目口径，落地须实测与人审。

## 1. 监理咨询与运维巡检的差异

电站与线路运维关注绝缘子破损、光伏热斑等 **设备缺陷**。监理依据规范、图集与专项方案开展巡视、旁站和平行检验，成果进入 **监理日志、通知单、危大工程专报、计量支付**。造价咨询还承担核量、变更签证与结算审计。

团体标准 T/CS 242-2025 将「数智监理」表述为对进度、质量、安全、环境的采集、分析、预警，以及施工单位整改闭环。起草单位包含交通工程监理企业。住建部智能建造导则亦写明：无人机航拍可辅助场平与基坑土方量测，并定期生成三维实景以展示进度。

## 2. 监理业务场景

| 监理业务 | 采集对象 | 智能分析产出 | 咨询与造价复用 |
|----------|----------|--------------|----------------|
| 安全巡视 / 危大工程 | 临边防护、安全帽与安全带、脚手架、深基坑、高边坡、吊装、红线侵占 | 违章检测、隐患点位、工单、专报影像 | 安全评估配图 |
| 进度控制 | 全场正射、实景三维、关键构筑物完成面 | 多期模型对比、形象进度、滞后预警 | 工期索赔、形象进度签证 |
| 质量控制 | 边坡坡率、结构点云与 BIM、混凝土表观、摊铺温度（红外） | 超挖欠挖、偏差超限、表观缺陷 | 质量争议留证 |
| 投资 / 计量 | 土石方表面、断面、弃土场 | 挖填方、运距辅助、变更工程量 | 结算核量、审计可视化 |
| 环保 / 文明施工 | 扬尘、积水、泥浆池溢流、弃土占道 | 环境事件识别 | 环水保监理记录 |
| 合同与资料 | 隐蔽部位、关键工序旁站补位 | 带坐标与时间戳的影像档案 | 竣工资料、争议证据链 |

危大工程仍须依法专项巡视与专报。无人机补充人员难以到达或难以通视的部位，**不能替代**基坑测斜、水位等规范监测。

几何类业务（土方、断面、BIM 叠模）依赖点云或其生成的 TIN、DEM、实景网格；安全帽、违停、区域入侵依赖二维照片或视频流。两条分析线可共用机巢，航线、载荷与分析软件不必绑定为同一套任务。

## 3. 国内公开案例

### 3.1 高速公路建设期巡检

**杭淳开高速杭州段（浙高信）**  
人工跑完全线约 180 公里约需 3 天；无人机约 3 小时出具报告，标注安全隐患、进度偏差与质量疑点。算法侧关注安全帽、安全绳、高处作业母绳；倾斜摄影用于边坡坡率。报道称综合效率提升超过 80%，典型隐患识别准确率不低于 85%，隐患到工单约 10 分钟。[杭州日报](https://hzdaily.hangzhou.com.cn/hzrb/2026/07/02/article_detail_1_20260702A066.html)

**苍泰高速**  
机巢按日巡检高边坡、桥梁、隧道口、临建与便道。算法识别逼近施工红线、排水渠积水，并以钉钉多维表闭环整改。三维模型辅助土石方进度与边坡形变，报道土方误差不超过 3%。[浙江省交通运输厅](https://jtyst.zj.gov.cn/art/2025/6/10/art_1228999548_59041827.html) · [中国城市网](https://www.zgcsb.com/news/jiaoTong/2025-06/04/ma_596339.html)

**福建高速建养**  
机场第二高速、漳诏改扩建等项目将实景三维与设计融合，检测施工安全条件；运营段可扩展至路面、边坡与桥梁病害。[福建省交通运输厅](https://jtyst.fujian.gov.cn/zwgk/jtyw/mtsy/202606/t20260630_7169569.htm)

监理多在业主或施工平台上复用影像，作为巡视记录与发文依据。

### 3.2 轨道交通建设期巡检

**市域铁路成德线**  
机巢自动巡航。算法识别深基坑隐患、烟雾、临边防护缺失与吊装监管，并可高空喊话。成都段高架约 18 km，报道 2 机 30 分钟一巡，效率提升 80% 以上。[封面新闻](https://www.thecover.cn/news/cXDIvZUYA92H90qSdq8Jkw==)

### 3.3 进度与 BIM / CIM 叠合

**渝昆高铁、狮子洋隧道等**  
大疆机场与司空平台按周更新实景三维，对接第三方 BIM，用于进度与质量可视化；桥墩、边坡、地基土方可基于点云量测。[大疆行业应用](https://enterprise.dji.com/cn/news/detail/dock2-smart-site-modeling)

**中建八局 · 国家能源集团雄安基地**  
五镜头倾斜摄影，报道精度不大于 5 cm，接入数字雄安 CIM；BIM 与实景融合用于全过程可视化。[报道](http://chifeng.gqsoso.com/chifeng/20260212/1436819.html)

**雄安商务服务中心（论文转述）**  
无人机点云与 BIM 比对，发现并整改偏差超限点 156 处。[质量管控策略研究](https://doi.org/10.37155/2811-0633-0422-4)

监理例会可用多期模型对照形象进度；几何偏差可作为平行检验的辅助证据。

### 3.4 造价咨询中的土石方核量

成都工程造价协会实践：倾斜摄影实景与设计 BIM 曲面叠模，计算挖填并暴露超挖欠挖，服务场平与线性道路结算；精度对标航测验收规范，断面可比传统 20 m 加密。[土方管理](http://cdzjxh.com/article_open.html?id1=4467) · [结算实践](http://cdzjxh.com/article_open.html?id1=5747)

武汉建筑协会实践：航测点云进入 Revit，以断面法做土方调配。[BIM 与航测土方](http://www.whjzyxh.org/index.php/View/8181.html)

咨询侧可单独报价第三方计量、变更签证与结算审计可视化，对人员防护识别准确率的依赖相对较低。

### 3.5 深基坑空中巡视与地面监测

杭州临平「天网地枢」：无人机观察基坑周边与支护宏观形态，测斜与水位反映微观变形，云端预警，精度对标《建筑基坑工程监测技术标准》GB 50497。[期刊介绍](https://www.qikanchina.com/thesis/view/1720513424)

无人机不能替代规范要求的测斜与水位。监理实施细则宜写明 **空中巡视与监测数据并行**。

## 4. 机场 2 的三条作业线

[大疆原文](https://enterprise.dji.com/cn/news/detail/dock2-smart-site-modeling) 与 [泰伯转载](https://www.taibo.cn/p/94831) 结构一致：同一套硬件（机场 2、M3D 与航线）划分为测绘建模、安全巡视、BIM 进度三条线。宣传口径以厂商稿为准，监理落地仍须人审与抽检。

新闻同时出现 **司空 2** 与 **大疆智图**，职责不同：

| 产品 | 角色 |
|------|------|
| **司空 2** | 云端任务中枢：远程规划航线、机巢起飞、直播分享、可选云端二三维、成果推送第三方 |
| **大疆智图** | 重建与量算软件（可本机运行）：将带 RTK 的航片生成点云、网格、正射，并在模型上量算土方 |

| 新闻项目 | 主产出 | 监理咨询对应 |
|----------|--------|----------------|
| 渝昆高铁 | 智图点云、土方、断面 / 沉降 / 墩位 | 计量、地基与结构几何巡视 |
| 西安东站 | 直播与安全帽、违停、入侵检测 | 安全巡视、空地协同 |
| 狮子洋 T6 | 周更实景与 BIM 叠合 | 形象进度、质量可视化 |

监理流水线可概括为：

```text
机巢按监理巡视计划起飞（日 / 周）
  → RGB / 倾斜摄影 / 可选红外、LiDAR
  → 正射影像 + 实景三维 / 点云
  → 两条分析线并行：
       A. 二维：人员防护、临边、烟火、积水、红线
       B. 三维：多期对比、坡率、土方、点云与 BIM
  → 隐患工单 / 监理通知单 / 计量报表
  → 整改复飞验收
```

| 技术 | 在监理咨询中的作用 |
|------|-------------------|
| 目标检测（YOLO 等） | 安全帽、反光衣、临边缺口、烟火、机械侵入红线 |
| 分割 / 变化检测 | 未防护洞口、裸土范围、周进度差异 |
| 倾斜摄影与点云 | 形象进度、可量测模型、边坡坡率 |
| BIM / CIM 叠合 | 图模一致性、构件完成面、偏差超限 |
| 断面 / TIN 土方算法 | 挖填方、变更核量 |
| 红外 | 大体积混凝土、沥青摊铺温度（标准文本有提及，现场成熟度因项目而异） |
| GIS 与即时通讯工单 | 整改时限，对应监理回复 |
| 时间戳 + RTK | 资料、审计与争议中的时空证据 |

视觉模型训练与推理常见于 PyTorch 生态；土方与表格统计仍使用 NumPy、pandas 及测绘软件。标准文本还涉及钢筋间距、混凝土表观等，现场成熟度一般低于土方核算和安全大目标识别，宜试点，不宜作为唯一验收手段。

## 5. 落地边界

1. 优先落地土方核量、形象进度与危大部位留影，投资边界清楚，争议相对较少。
2. 安全类识别须经人审后再发监理通知单；误报会损害监理文件效力。
3. 空域、飞手资质、保险及与总包机巢权属写入监理规划与合同附件。
4. 输出对齐现有表式：巡视记录、通知单、危大专报、计量支付，避免另建一套运维缺陷库。
5. 报道中的 80%、85%、3% 等数字来自具体项目宣传，招标与验收应改写为可抽检指标与抽检规程。

## 6. 小结

| 要点 | 结论 |
|------|------|
| 业务对齐 | 质量、进度、安全、投资四控；输出进入监理与计量资料 |
| 国内主战场 | 高速公路与轨道建设期机巢巡检；房建侧 BIM 点云与土方咨询 |
| 两条分析线 | 几何依赖点云、网格、正射；安全依赖二维照片或视频流 |
| 咨询差异化 | 土石方第三方核量与结算可视化 |
| 不可替代 | 危大专巡法定职责、基坑规范监测、质量平行检验中的人判 |
