# 基于无人机的空间数据感知识别与应用

> 无人机航测输出点云、正射与倾斜摄影。测绘与监理需要的是可识别目标体：地面、建筑单体、树障、水域、沉降面。西安新生代智能科技官网产品 **云集建模** 将链路表述为空间数据感知识别与应用：多源点云接入 → 离散建模与提取 → 单体化、白模及 GIS / CAD 输出。下文依据 [dmi42.com](https://www.dmi42.com/) 公开栏目归纳。指标与案例为厂商口径，落地须用本测区数据实测。

## 1. 无人机采集与空间感知的接口

机载作业常见数据入口，官网并列写出：**LiDAR、InSAR、摄影测量**。与旋翼无人机直接相关的是激光点云（LAS 等），以及可见光重叠像片重建得到的点云、正射（GeoTIFF）和倾斜网格。InSAR 多为卫星或专用雷达，载荷与旋翼机不同，但被纳入同一套多源异构空间数据平台。

感知的目标不是提高点云渲染观感，而是利用三维坐标对空间物体做自动识别、计算与应用：建筑物、地形、植被、水域、线路走廊等。缺少这一步，航测成果停留在可浏览的实景；具备这一步，才能进入树障分析、沉降、白模入库与变化检测。

官网主体为 Windows 桌面软件 **云集建模（DMI）**，开发方为西安新生代智能科技有限公司，对外表述为长期从事点云空间计算，服务测绘、电力、地质灾害、能源等行业。页内建筑、车辆、城市等 Web 三维演示用于展示单体化与白模，不是飞控或机巢产品。

## 2. 离散建模与技术架构

厂商将核心概念称为 **离散建模**：在空间离散（点云）上构建空间关系模型，以 AI 完成特征提取和目标体识别。实现上分为智能提取、统计分析（含 QA/QC、回归）与大规模计算。阶段成果被表述为优先解决准确率与效率。

架构可概括为：

```text
感知模型 → 特征模型 → 矢量模型
  → 智能提取模型
  → 统计分析模型（QA / QC）
  → 大规模计算模型（AI 处理器）
  → 基础数据平台（InSAR / 正射 / 倾斜 / 激光雷达）
```

| 模块 | 官网表述的职责 |
|------|----------------|
| 智能提取 | 从海量点云识别建筑物、地形、植被等目标体 |
| 统计分析 | QA/QC、回归分析，为处理精度和决策提供统计支撑 |
| 大规模计算 | 并行提取与识别；宣传速度为每秒 5 万点 |
| 基础数据平台 | 统一管理多源空间数据，融合多种采集手段 |

「离散」对应点云作为表面抽样；「建模」指在点之间恢复可计算的空间关系（地面、单体、矢量），而不是仅贴附航片纹理。

正射和倾斜影像不走点云分类时，开源侧常用两条影像链路：没有标注时用 SamGEO 做分割，有标注、要可重复训练时用 Raster Vision。

## 3. SamGEO 与 Raster Vision

两者都吃带地理参考的大幅影像（含无人机正射、倾斜片），输出仍带坐标的栅格或矢量。它们不替代激光点云上的地面分类和树障量算。

### 3.1 SamGEO

[SamGeo](https://github.com/opengeos/segment-geospatial)（包名 `segment-geospatial`，导入名 `samgeo`）把 Meta 的 Segment Anything 系列接到遥感影像上。灵感来自 segment-anything-eo，目标是少写代码就能对 GeoTIFF 出掩膜。包装的模型包括 SAM、SAM 2、SAM 3、FastSAM、HQ-SAM，以及用文字提示的 LangSAM。

| 能力 | 说明 |
|------|------|
| 输入 | GeoTIFF、PNG、JPG、数组或瓦片服务；可用 `tms_to_geotiff` 把底图框成 GeoTIFF |
| 提示 | 自动撒点出掩膜；也可给前景/背景点、框，或文字（如水体、屋顶） |
| 输出 | 掩膜 GeoTIFF（`unique=True` 时每个对象一个编号）；再转 GeoPackage、Shapefile、GeoJSON |
| 其它 | 时序影像分割、交互地图查看、HTTP API；QGIS 插件与 ArcGIS 工具箱 |

自动分割时，点密度、IoU 阈值、稳定度、裁块层数和最小斑块面积决定小目标会不会被丢掉、相邻屋顶会不会粘成一片。正射上适合先分出建筑、水域、裸地等「看起来是一整块」的区域，再交给 GIS 量算面积。它不认识电力规程里的树障距离，也不输出点云里的地面点。

### 3.2 Raster Vision

[Raster Vision](https://github.com/azavea/raster-vision)（Azavea，Apache-2.0）是面向卫星、航片和**倾斜无人机影像**的计算机视觉框架，后端是 PyTorch。它同时当库和低代码实验流水线：读地理参考数据、切训练切片、训练、预测、评价，再把预测写回带坐标的格式。

| 任务 | 典型用途 |
|------|----------|
| 语义分割 | 像素级的建筑、植被、道路、水体 |
| 目标检测 | 车辆、杆塔、光伏板等可框出的地物 |
| 切片分类 | 一块芯片是不是某类地物 |

流水线固定为：统计训练数据 → 切芯片 → 训练 → 预测 → 评价 → 打包模型和配置。大图不能整幅送进网络，切片和重叠是它处理航片幅宽的方式。实验可放到 AWS Batch 或 SageMaker。`pip install rastervision`，也可用 quay.io 上的 Docker 镜像。

和 SamGEO 的差别是：Raster Vision 要标注和一次可复现的训练；SamGEO 用基础分割模型直接出掩膜，换测区时调的是阈值而不是重训。检测框和类别若必须稳定（例如只要红色工程车），Raster Vision 更合适；只要把正射上连成片的屋顶或水面矢量化，SamGEO 更短。

```text
无人机正射 / 倾斜 GeoTIFF
  → SamGEO：自动或文字/点/框提示 → 掩膜 → 矢量
  → Raster Vision：标注切片 → 训练分割或检测 → 带坐标的预测
点云 LAS
  → 仍走地面分类、单体化与树障（上文离散建模）
```

## 4. 点云到实体模型的功能

实用功能归纳为六项，覆盖接入、提取、重构、校准、滤波和导出：

| 功能 | 要点 |
|------|------|
| 快速地表精细提取 | 宣传「数千万点、分钟级」生成高精度地表模型 |
| 全自动单体化与矢量重构 | 单体识别、矢量重构、材质外表，并自动赋色 |
| 全自动校准与数据修复 | 校准、对比统计、数据与设备修复；宣传姿态精度 0.001°（与设备和飞行相关） |
| 多源格式 | LAS、GeoTIFF 等；激光雷达、摄影测量、InSAR |
| 杂点分析与滤除 | 按地理、气象、遥感设备的杂波特征去噪 |
| 多平台输出 | GIS、CAD 等 |

单体化重构与摄影测量「点云 → 网格 → 贴图」同构，但强调可点选实体，而不是不可分割的整片三角网：

```text
机载激光高密度点云
  → 初始曲面重建
  → 面片合并（PolyMerge）与单体化
  → 正射纹理映射 → 带纹理的三维实体
```

页内建筑、车辆演示采用同一套 PolyMerge 展示；城市演示以建筑高度色阶为体块白模着色。

## 5. 行业应用

应用栏目覆盖测绘制图、智慧巡检、地质灾害、农业环境，并称已完成大批量、多地区数据验证。与无人机巡检较接近的是电力走廊与地表变化：

| 场景 | 点云上的处理 |
|------|----------------|
| 电力线路智能巡检 | 在地表精细模型上分析树障与地表沉降；写明已完成陕西电网项目 |
| 地质灾害排查 | 孔洞渗漏、植被下隐性空洞与裂缝；可计算孔洞深度、孔径、距离 |
| 水域提取 | 水陆边界、水域变化、水域高程；有落差水域可生成均匀梯度 |
| 剥离植被层 | 激光穿过树灌草缝隙到达地面，识别植被下真实地表 |
| 地表精细特征 | 可表现特征宣传在 0.15 m 以内，精度由 10 厘米级向厘米级推进 |
| 矢量化白模 | 大范围特征提取与矢量化，生成城市级白模 |
| 全自动对比拟合 | 依据地表目标体的空间相似性做对比拟合，支撑变化检测与质量分析 |

树障、沉降、剥植被、变化检测依赖分类后的地面点与目标体，而不是仅依赖正射。机载激光比纯可见光重建更容易穿过冠层到达真实地面，因此官网将 LiDAR 列在采集手段首位；倾斜摄影仍可作为纹理和补点来源。

## 6. 城市级单体化演示规模

城市建模栏目强调：由原始点云直接生成可点选单体，自动提取、单体化、矢量重构、高度着色一次批量完成，无需逐栋人工干预。两组页内交互成果如下（数字来自演示页）：

| 演示 | 规模 | 覆盖 | 最高建筑 | 说明 |
|------|------|------|----------|------|
| 城市-1 | 147 栋，61,234 三角面 | 2.29 × 2.06 km | 240 m | LOD 1 体块白模，高度色阶 |
| 城市-2 | 1,655 栋，69,426 三角面 | 1.00 × 1.00 km | 28 m | PolyMerge 大批量低层街区 |

首页将单次覆盖写为约 4.72 km²（与城市-1 的 2.29 × 2.06 km 一致），并强调每栋为独立实体而非整片网格。LOD 1 白模可进入 GIS、CAD 与三维平台；精细立面和室内不属于该档演示。

## 7. 性能口径与产品边界

技术指标栏目将算力表述为：消费级 GPU 上 50,000 点/秒的提取与识别，精细特征由 10 cm 向厘米级推进。技术特色包括多地区数据验证、底层自主开发、宣称不借助开源与第三方库、兼容各类机载激光与短长测距、可深度定制与硬件集成。上述均为厂商自我描述。招标或验收应改为可抽检的精度、耗时和分类指标。

软件侧见 [下载页](https://www.dmi42.com/download.html)：Windows 10/11 64 位桌面程序，通用安装包配合人工审核激活码；试用期宣传约 30 天、一码一机。无激活码可以安装，激活后才能使用。该软件处理已经落地的点云与影像，不替代航线规划、RTK 像控和空三。无人机负责采集可量测的空间数据。

## 8. 小结

| 要点 | 结论 |
|------|------|
| 采集 | 无人机侧主要为 LiDAR 点云与摄影测量（正射 / 倾斜）；InSAR 为平台中的另一类数据源 |
| 感知 | 自动识别地面、建筑、植被、水域等，而不是仅输出实景浏览模型 |
| 重构 | 点云 → 曲面 → PolyMerge 单体化 → 正射纹理；城市演示以 LOD 1 白模为主 |
| 影像开源工具 | SamGEO 对正射做零样本分割并出矢量；Raster Vision 在有标注时训练分割与检测 |
| 巡检 | 树障、沉降、剥植被、变化拟合依赖几何分类 |
| 口径 | 每秒 5 万点、0.001°、0.15 m 特征等来自官网，须用本测区实测 |
